## Open P0 blocker: checkpoint save

Both arms reproduced the same failure after all four train steps:

1. `async_save=False` and `--disable-msc` were active.
2. About 3.7 TiB of `.distcp` shards were written.
3. No `.metadata` or `latest_checkpointed_iteration.txt` appeared.
4. Checkpoint child processes became zombies with exit code 11.
5. All trainer parents remained blocked in `MegatronTrainRayActor.save_model`.

The preserved FP8 actor log shows this immediately before two crashes:

```text
Rank 28 common state dict differs from rank 0 common state dict.
Mismatched keys: [(('args',), argparse.Namespace, argparse.Namespace)]
!!!!!!! Segfault encountered !!!!!!!
.../go/.../runtime/sys_linux_arm64.s: runtime.sigfwd
```

`--disable-msc` changed the storage selection but did not prevent the Go-linked
signal path or multiprocessing children. Do not assume the crash belongs solely
to MSC, Megatron, or PyTorch until a native backtrace identifies the loaded
library.

No native core was captured. The BF16 per-actor file was not archived; its
combined Slurm log and the process/exit-code evidence are recorded in the
chronological experiment log.
